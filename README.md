## Featured Project: PhishGuard-AI

**Question:** In machine-learning-based phishing detection, how much does URL scheme information (**HTTP vs. HTTPS**) contribute to a model's decisions?

HTTPS was once treated as a signal of trust, yet phishing sites now commonly use it too. PhishGuard-AI investigates the role of scheme-based features in phishing classifiers and what that means for building robust detectors.

**What the repository contains** *(edit to match your actual repo)*
